# Archive

Superseded planning documents, kept for provenance only.

`IDEA.md` at the repo root is the plan of record. `RESULTS.md` is generated by
`npm run eval` and is the only source of numbers. Anything in this folder that
disagrees with those two is stale by definition — in particular these documents
predate: the deletion of the second evaluator, the switch of the world's dormancy
churn from a piecewise table to a logistic with per-customer heterogeneity, and
the compliance gate.
